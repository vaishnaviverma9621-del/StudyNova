Lesson 5: Loops

For Loop

for i in range(5):
    print(i)

While Loop

i = 1

while i <= 5:
    print(i)
    i += 1

Loop Control Statements

  • break – stops the loop
  • continue – skips the current iteration
  • pass – does nothing
