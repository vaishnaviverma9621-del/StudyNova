3. Operators

Operators are symbols used to perform operations on values.

Types of Operators

  • Arithmetic: +, -, *, /, %
  • Relational: >, <, ==, !=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=

Example

int a = 10;
int b = 5;

int sum = a + b;
