Lesson 6: Functions

What is a Function?

A function is a block of reusable code that performs a specific task.

Defining a Function

def greet():
    print("Hello, StudyNova!")

Calling a Function

greet()

Function with Parameter

def greet(name):
    print("Hello", name)

greet("Student")

Return Statement

def add(a, b):
    return a + b

result = add(5, 3)
print(result)
