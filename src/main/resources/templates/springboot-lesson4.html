Spring Boot Controllers

Learn how Controllers handle requests in Spring Boot.

🎯 What is a Controller?

A Controller is a Spring Boot component that handles requests from the user and returns a response.

Controllers are commonly used to open web pages or create API endpoints.

@Controller Annotation

The @Controller annotation tells Spring that a class is responsible for handling web requests.

Simple Example 

@Controller
public class HomeController {

    @GetMapping("/home")
    public String home() {
        return "home";
    }
}

🔗 @GetMapping

The @GetMapping annotation maps a URL to a method in the Controller.

Example: /home request will call the home() method.

📌 Key Points

  • Controller handles web requests.
  • @Controller is used to create a web controller.
  • @GetMapping maps GET requests to methods.
  • Controller can return a Thymeleaf HTML page.
