Object-Oriented Programming

OOP is a programming approach based on objects and classes.

Main OOP Concepts

  • Class
  • Object
  • Inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction

Example

class Student {
    String name;

    void study() {
        System.out.println("Student is studying");
    }
}
