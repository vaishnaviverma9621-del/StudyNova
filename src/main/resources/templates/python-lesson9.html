Lesson 9: Object-Oriented Programming

What is OOP?

Object-Oriented Programming is a programming approach based on classes and objects.

Class and Object

class Student:
    def __init__(self, name):
        self.name = name

student1 = Student("Rahul")

print(student1.name)

Constructor

The __init__() method is used to initialize an object's attributes.

Inheritance

class Animal:
    def speak(self):
        print("Animal speaks")

class Dog(Animal):
    pass

dog = Dog()
dog.speak()
