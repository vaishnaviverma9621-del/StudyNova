Lesson 3: CSS Basics

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML web pages.

Basic CSS

h1 {
    color: blue;
    font-size: 30px;
}

p {
    color: gray;
}

Ways to Add CSS

  • Inline CSS
  • Internal CSS
  • External CSS

Example

<h1 style="color: blue;">
    StudyNova
</h1>
💡 HTML creates structure and CSS controls the appearance.
