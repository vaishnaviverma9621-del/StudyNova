Lesson 4: Conditional Statements

if Statement

Conditional statements are used to execute different blocks of code depending on a condition. 

age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

Types

  • if
  • if-else
  • if-elif-else
