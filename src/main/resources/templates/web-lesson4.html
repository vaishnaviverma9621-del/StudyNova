Lesson 4: CSS Layout & Flexbox

What is Flexbox?

Flexbox is a CSS layout system used to arrange elements easily in rows or columns. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

Important Properties

  • display: flex
  • justify-content
  • align-items
  • flex-direction
  • gap
💡 Flexbox helps create flexible and organized layouts.
