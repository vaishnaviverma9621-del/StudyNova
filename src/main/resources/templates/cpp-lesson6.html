6. Functions

A function is a block of code designed to perform a specific task. Functions help make programs organized and reusable.

Example

int add(int a, int b) {
    return a + b;
}

int result = add(10, 5);

Advantages

  • Code reusability
  • Easy debugging
  • Better program structure
