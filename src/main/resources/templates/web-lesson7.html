Lesson 7: JavaScript DOM

What is DOM?

DOM stands for Document Object Model. It allows JavaScript to access and change HTML elements. 

<h1 id="title">Hello</h1>

<script>
document.getElementById("title").innerText = "StudyNova";
</script>

Event Example

button.addEventListener("click", function() {
    alert("Button clicked!");
});
💡 DOM allows JavaScript to interact with webpage elements.
