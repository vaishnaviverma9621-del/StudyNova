Lesson 8: File Handling

What is File Handling?

File handling allows Python programs to create, read, write and modify files.

Opening a File

file = open("student.txt", "r")
data = file.read()
print(data)
file.close()

Writing to a File

file = open("student.txt", "w")
file.write("Welcome to StudyNova!")
file.close()

Using with Statement

with open("student.txt", "r") as file:
    data = file.read()
    print(data)

The with statement automatically closes the file after the operation is completed.
