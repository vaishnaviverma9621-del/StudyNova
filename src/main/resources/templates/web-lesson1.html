Lesson 1: HTML Basics

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

Basic HTML Structure

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>Welcome to my website.</p>
</body>

</html>

Common HTML Tags

  • <h1> - Heading
  • <p> - Paragraph
  • <a> - Link
  • <img> - Image
  • <button> - Button
  • <div> - Container
