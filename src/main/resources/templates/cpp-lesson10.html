10. Mini Project

Let's create a simple program to calculate the total and average marks of three subjects. 

#include <stdio.h>

int main() {

    int a = 80;
    int b = 75;
    int c = 90;

    int total = a + b + c;

    float average = total / 3.0;

    printf("Total = %d\n", total);
    printf("Average = %.2f", average);

    return 0;
}

This project combines variables, operators and output to create a simple marks calculator.
