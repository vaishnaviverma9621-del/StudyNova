Lesson 7: Python Data Structures

What are Data Structures?

Data structures are used to store and organize data so that it can be accessed and managed easily.

1. List

A list is ordered, changeable and allows duplicate values. 

fruits = ["Apple", "Mango", "Banana"]

print(fruits)
print(fruits[0])

2. Tuple

A tuple is ordered but cannot be changed after creation. 

numbers = (10, 20, 30)

print(numbers)

3. Dictionary

A dictionary stores data in key-value pairs. 

student = {
    "name": "Rahul",
    "age": 20
}

print(student["name"])

4. Set

A set is an unordered collection that does not allow duplicate values. 

numbers = {1, 2, 3, 3}

print(numbers)
