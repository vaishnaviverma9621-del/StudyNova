Lesson 2: HTML Forms & Tables

HTML Tables

Tables are used to display information in rows and columns.

<table>
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>Java</td>
    </tr>
</table>

HTML Forms

Forms are used to collect information from users.

<form>
    <label>Name</label>
    <input type="text">

    <label>Email</label>
    <input type="email">

    <button type="submit">Submit</button>
</form>
💡 Forms collect user input, while tables organize information.
