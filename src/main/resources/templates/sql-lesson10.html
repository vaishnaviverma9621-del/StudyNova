10. Mini SQL Project

Let's create a simple student database.

Create Table

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    course VARCHAR(50),
    marks INT
);

Insert Data

INSERT INTO students
VALUES (1, 'Aman', 'BCA', 85);

Display Students

SELECT * FROM students;

This mini project demonstrates the basic use of SQL for storing and retrieving student data.
