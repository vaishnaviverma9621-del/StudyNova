Lesson 3: Control Statements

if-else Statement

It is used to execute code based on a condition.

if(age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

Loops

  • while loop
  • do-while loop

Switch Statement

Switch is used when we need to choose one option from multiple cases.
