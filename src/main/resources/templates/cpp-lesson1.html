1. Introduction to C

C is a general-purpose programming language. It is widely used for system programming, embedded systems and application development.

Basic C Program

#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}

Important Features

  • Simple and efficient
  • Structured programming
  • Fast execution
  • Supports pointers
